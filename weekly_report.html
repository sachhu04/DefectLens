DefectLens: Efficient ViT-Based Anomaly Detection with Multi-Criteria Token Fusion (MCTF)

Sachin Singh
Roll No: 2023bcs0064
Weekly Project Write-Up
Course: Computer Vision
Abstract. This weekly report outlines the foundational requirements for the DefectLens project. It details the core problem of computational inefficiency in Vision Transformers (ViTs) for high-resolution industrial anomaly detection, the motivation behind applying a Multi-Criteria Token Fusion (MCTF) architecture for real-time edge deployment, and the specific objectives the project intends to achieve to solve the accuracy-latency trade-off.

I. Problem Statement

Industrial visual inspection is paramount for maintaining manufacturing quality control. Traditional supervised learning approaches are fundamentally constrained as they require exhaustively labeled datasets for every conceivable defect type—a practical impossibility given the rarity, subtlety, and unpredictable nature of manufacturing flaws. Consequently, unsupervised anomaly detection—learning the manifold of pristine "normal" products—has emerged as the standard paradigm.

While Vision Transformers (ViTs) have achieved state-of-the-art performance in these tasks by capturing comprehensive global context and rich patch-level representations, they inherently suffer from massive computational overhead due to their quadratic complexity with sequence length. In industrial scenarios where high throughput (low latency) and high-resolution imaging are critical, the fixed and highly redundant token processing of standard ViTs introduces a debilitating bottleneck. The core problem this project addresses is: How can we drastically reduce the computational footprint of ViTs for anomaly detection without sacrificing the high-resolution, fine-grained visual details required for accurate defect localization?

II. Motivation & Application

Failing to detect subtle defects can lead to catastrophic product failures, massive recalls, and safety hazards, particularly in precision industries like aerospace, medical devices, and semiconductor manufacturing. Conversely, an overly slow inspection system creates a severe production bottleneck, reducing yield. Resolving the latency-accuracy trade-off is critical for enabling next-generation smart manufacturing and Industry 4.0.

The primary motivation stems from the stringent operational demands of modern manufacturing pipelines, which require inspection mechanisms to be both exceptionally accurate and blisteringly fast. Standard CNN-based models often struggle with complex global geometries and textures, while standard ViTs are too computationally dense for real-time edge deployment on automated production lines.

This project is specifically designed for deployment in Automated Optical Inspection (AOI) systems located directly on factory floors. By leveraging a high-performance, optimized anomaly detection model, manufacturers can instantly identify structural defects, surface contaminations, and assembly errors (comparable to those found in the MVTec AD dataset) in real-time as products move rapidly along a conveyor belt.

III. Objectives

The central objective of DefectLens is to engineer an optimized, high-throughput industrial anomaly detection architecture that harnesses the profound representational power of Vision Transformers while systematically mitigating their computational drawbacks. Specifically, the project intends to achieve the following:

  • Establish a Vision Transformer architecture coupled with a Memory Bank (PatchCore-style) to create a robust foundation for unsupervised anomaly detection.
  • Integrate a Multi-Criteria Token Fusion (MCTF) module that dynamically identifies and merges redundant background tokens across ViT layers.
  • Implement specialized criteria—including token similarity, informativeness (via one-step-ahead attention), and token size penalties—to ensure that small but critical defect representations are protected.
  • Drastically reduce the Floating Point Operations (FLOPs) and overall end-to-end latency by reducing token counts, making the model viable for high-speed edge inference.
  • Deliver an end-to-end system by packaging the model with a functional FastAPI backend and a React-based frontend to simulate a real-world quality control dashboard.

2. PROJECT OVERVIEW

The DefectLens project is a visual anomaly detection system designed to inspect industrial products for manufacturing defects. We combine a Vision Transformer (ViT) backbone with a PatchCore-style FAISS memory bank. To make the model fast enough for edge and real-time use, we developed a Multi-Criteria Token Fusion (MCTF) module that dynamically merges uninformative background patch tokens while protecting defect tokens.

Task 7 Part 4 Focus (100% Implementation): In this final milestone, Team 7 has reached 100% completion of the proposed methodology. Building on the integrated prototype from Task 6, we completed the full quantitative benchmarking (evaluating AUROC scores and latency on the MVTec AD dataset), conducted thorough integration testing across all modules, and prepared the final source code repository.

5. EXPERIMENTAL RESULTS & PERFORMANCE EVALUATION

To evaluate the efficiency and accuracy of our proposed MCTF approach, we ran automated benchmark evaluations (scripts/evaluate.py) over the MVTec AD test set for the bottle category (209 training images and 83 test images). We tested both the standard Baseline ViT (without token fusion) and our MCTF-ViT on the same machine to measure the exact differences in speed, token count, and detection accuracy.

Model Tokens Token Reduction Avg Latency Image AUROC Pixel AUROC
Baseline ViT 196 0.0% 45.07 ms 100.0% 98.68%
MCTF-ViT (Ours) 23 88.27% 19.73 ms 94.92% 92.90%
Figure 2. Automated evaluation benchmark output. Terminal execution showing MCTF achieving an average latency of 19.73 ms (2.28x faster than baseline), an 88.27% token reduction, 94.92% Image AUROC, and 92.90% Pixel AUROC.

Key Findings:

  • Speed Improvement: MCTF cut average per-image inference latency from 45.07 ms down to 19.73 ms, making the system 2.28x faster (a 56.2% reduction in inference time).
  • Token Efficiency: The number of tokens processed by subsequent layers was reduced from 196 to only 23 (an 88.27% reduction).
  • Accuracy Preservation: Despite fusing almost 90% of tokens, the model retained 94.92% Image AUROC and 92.90% Pixel AUROC, confirming that our informativeness criterion successfully prevents defect patches from being lost.

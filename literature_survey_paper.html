Abstract—Automated Optical Inspection (AOI) in smart manufacturing requires high precision to localize subtle defects while strictly maintaining high throughput. While Vision Transformers (ViTs) and nearest-neighbor patch-memory banks (e.g., PatchCore) represent state-of-the-art visual anomaly detection, ViTs incur quadratic computational complexity (O(N2)) with image token length, causing latency bottlenecks on edge hardware. This report conducts a concise survey of 8 canonical peer-reviewed research papers across memory-bank modeling, reconstruction, normalizing flows, unified transformers, and token reduction. We provide an IEEE comparative matrix, delineate core research gaps, and demonstrate how DefectLens overcomes these challenges via Multi-Criteria Token Fusion (MCTF) with informativeness shielding.

I. Introduction

Industrial surface inspection ensures component reliability across manufacturing sectors. Because real-world defects are rare and unpredictable, Unsupervised Visual Anomaly Detection (VAD) trains exclusively on pristine ("normal") parts, flagging flaws as out-of-distribution deviations during inference.

While Vision Transformers (ViTs) capture superior global context compared to CNNs, quadratic self-attention scaling (N = (H/P) × (W/P)) on high-resolution inputs (512×512, N = 1024) leads to high latency (~45ms/frame). To resolve this, DefectLens combines ViTs with Multi-Criteria Token Fusion (MCTF) and a FAISS PatchCore memory bank.

II. Survey of 8 Canonical Research Papers

1. PatchCore (Roth et al., CVPR 2022) [1]: Extracts locally aggregated CNN patch features into a memory bank subsampled via Minimax Coreset, scoring anomalies by nearest-neighbor distance. Achieves 99.1% Image AUROC and 98.1% Pixel AUROC on MVTec AD. Limitations: High latency on high-res images; CNNs lack global context.

2. MVTec AD Benchmark (Bergmann et al., CVPR 2019) [2]: Establishes the standard industrial benchmark and evaluates baseline Autoencoders (SSIM-AE, L2-AE) and VAEs, yielding 70.0%–82.0% Image AUROC. Limitations: Suffer from identical reconstruction shortcuts (reconstructing defects) and edge blurriness.

3. PaDiM (Defard et al., ICPR 2020) [3]: Models patch embeddings across CNN layers as localized multivariate Gaussians N(μ(i,j), Σ(i,j)), scoring by Mahalanobis distance. Achieves 97.9% Image AUROC and 97.5% Pixel AUROC. Limitations: Requires rigid spatial alignment; covariance storage scales as O(HW · D2).

4. MCTF (Lee, Choi, & Kim, CVPR 2024) [4]: Introduces token reduction in ViTs using Cosine Similarity, One-step-ahead Attention (shielding informative tokens), and Size penalties. Achieves 44% FLOP reduction with a +0.5% accuracy increase on ImageNet. Limitations: Evaluated only on classification; never applied to anomaly detection.

5. Token Merging (ToMe) (Bolya et al., ICLR 2023) [5]: Bipartite soft matching merging top-r similar tokens via key similarity, achieving a 2.0× speedup and 44% GFLOP reduction. Limitations: Pure similarity merging destroys small anomaly tokens by merging them into background clusters.

6. UniAD (You et al., NeurIPS 2022) [6]: Unified multi-class transformer detector with Query Decoder and Neighbor-Masked Attention (NMA). Achieves 96.5% Image AUROC and 96.8% Pixel AUROC. Limitations: Heavy training cost; high latency (~65ms) limits edge deployment.

7. FastFlow (Yu et al., arXiv 2021) [7]: 2D Normalizing Flows mapping spatial ViT/CaiT features to a 2D Gaussian distribution. Achieves 99.4% Image AUROC (CaiT) and 98.8% (ViT-B). Limitations: High inference computation for invertible flow layers; large model weight footprint.

8. Reverse Distillation (Deng & Li, CVPR 2022) [8]: Teacher-Student distillation with reverse One-Class Embedding bottleneck, scoring via cosine divergence. Achieves 98.5% Image AUROC and 97.8% Pixel AUROC at ~45 FPS. Limitations: Category-specific student retraining; cannot dynamically prune tokens.

III. Identification of Research Gaps in Existing Work

Comparative review of the literature reveals four critical open research gaps:

1. Quadratic Complexity of ViTs in High-Resolution AOI:
Self-attention scales as O(N2) with token sequence length N. For high-resolution inspection (512×512, N = 1024), standard ViTs incur ~45ms latency per image, creating throughput bottlenecks on fast factory lines.
2. Catastrophic Defect Elimination in Naive Token Pruning (ToMe):
Existing token reduction methods rely purely on feature similarity. In surface inspection, subtle flaws occupy only 1–4 tokens out of 1024. Pure similarity merging fuses anomaly tokens into massive background clusters, irreversibly destroying defect sensitivity.
3. Memory Bank Scalability & Coordinate Tracking:
Memory-bank models (PatchCore) query 1,024 unpruned tokens per frame against millions of FAISS vectors, causing high search latency. Furthermore, spatial coordinates must be preserved during reduction to render accurate pixel-level heatmaps.
4. Absence of Token Fusion in Industrial Anomaly Detection:
Advanced token fusion methods like MCTF [4] were developed strictly for closed-set classification and have never been adapted for unsupervised VAD or integrated with nearest-neighbor memory banks.

IV. How DefectLens Relates to & Differs from Existing Work

DefectLens addresses each identified gap through a novel architectural synergy combining Vision Transformers, Multi-Criteria Token Fusion, and FAISS memory banks:

1. Architectural Synergy (ViT + MCTF + Memory Bank):
Unlike PatchCore (static CNNs) or ToMe (defect feature collapse), DefectLens embeds an MCTF module between ViT blocks to dynamically prune redundant background tokens while querying normal representations from a FAISS vector index, combining global context with high inference speeds.
2. Tri-Fold Fusion Safeguard with Attention Informativeness:
DefectLens enforces a tripartite policy: (i) Cosine Similarity fuses redundant background tokens; (ii) One-Step-Ahead Attention inspects deeper layers to shield informative defect tokens; (iii) Token Size Penalty prevents representation collapse and preserves localization fidelity.
3. Full End-to-End Production System:
Unlike theoretical research scripts, DefectLens delivers a full production stack featuring a FastAPI backend and an interactive React Automated Optical Inspection dashboard with real-time heatmap visualization.

V. Conclusion

DefectLens establishes an efficient, high-throughput visual anomaly detection pipeline for smart manufacturing. By replacing rigid patch extraction with Multi-Criteria Token Fusion, the framework bridges the accuracy-efficiency divide in Automated Optical Inspection.

2. PROJECT OVERVIEW

The DefectLens project is a visual anomaly detection system for identifying manufacturing defects. We are using a Vision Transformer (ViT) combined with a PatchCore-style FAISS memory bank. To improve efficiency, we added a Multi-Criteria Token Fusion (MCTF) module that dynamically merges redundant background tokens, which helps reduce inference latency and FLOPs while maintaining accuracy.

Task 6 Part 3 Focus: This milestone targets 75% overall implementation. We have successfully developed the React.js frontend interface and integrated all existing modules (ViT, MCTF, FAISS, FastAPI) into a complete, working prototype. The system can now accept user uploads via the browser, process them through our deep learning pipeline, and return real-time visual heatmaps and metrics back to the UI.
